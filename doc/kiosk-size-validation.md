## 完整性和功能

- 23 项 ARM64 Python 回归通过：12 项 kiosk、6 项画板索引恢复、5 项精简边界/容量/dpkg 安装检查。真实 deb 安装检查覆盖后续升级中的许可证、文档目录别名、中文翻译及运行资源保留。
- FAT/ext4 只读检查、MBR/Allwinner BootROM 校验和、设备树、内核命名空间/seccomp、普通用户加载 App、kiosk/音频/Wi-Fi 服务配置和 `dpkg --audit` 通过；APT 依赖检查通过。
- 新旧镜像均为相同版本的 584 个包。比较 `usr` 和 `boot` 下 13,729 个运行路径（不含被精简的文档、手册、系统 gettext 翻译），运行文件/符号链接没有增删或内容变化。唯一字节不同的是重新生成的 `initrd.img-*` 归档，其解包后的全部 229 个路径内容一致；实际 extlinux 使用的 `uInitrd` 字节相同。
- `dpkg --verify` 的差异全部为明确精简的 1,146 项普通文档、2,854 项手册、2,109 项非中英文系统翻译，以及原镜像已有的 46 项内核 boot 路径搬移，没有额外差异。许可证保留，Qt/WebEngine 语言资源、字体、拼音词库、Mesa/LLVM、音视频、固件与模块均未精简。
- 在只读挂载的新镜像中，以普通用户运行发布安装包，完成首页新建、画一笔、返回保存、终止进程、重启并重新打开。存档 bank 为 generation 2，重新打开日志确认 1 条笔迹记录。测试使用 tmpfs 中的合成画板，没有向镜像加入个人数据。
